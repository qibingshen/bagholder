## 安全边界确认

- 所有量化数字必须来自 MCP 工具结果、工具版本、参数摘要、数据版本、新鲜度和来源记录。
- 工具失败、超时、资源限额或部分结果不得被解释成完整量化结论。
- Skill 只能调用清单内工具，越权调用必须拒绝并记录脱敏审计。
- 非本机调用、发布、回滚、删除、凭据管理、券商登录和交易工具在首个阶段必须拒绝。
- 大模型回答缺少事实引用时必须返回拒绝说明：不能脱离 MCP 工具结果生成量化数字。

## 复验要求

当 MCP 工具字段、权限边界、Skill 清单、超时限额、任务幂等、对话编排、数字溯源或研究页面降级状态发生变更时，必须重新运行本记录中的指定测试。任一测试失败时，不得声明 US3 可独立验收。
