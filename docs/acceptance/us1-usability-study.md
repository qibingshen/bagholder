# US1 真实用户可用性研究协议与结果记录

## 当前状态

**待真实参与者执行。**

本文件是研究协议和空白结果表，不是可用性验收通过记录。未完成招募、知情同意、真实任务执行和结果复核前，不得填写成功率、完成时长、观察结论或“通过”。

## 研究目标与成功标准

目标是验证使用个人电脑研究股票的个人投资研究者，能否在不接收投资建议的前提下理解并完成 US1 本地市场历史查看旅程。

- 目标参与者：使用个人电脑进行股票研究的个人投资研究者。
- 最低样本量：10 名真实参与者。
- 主要成功标准：至少 90% 的参与者在 3 分钟内独立完成核心任务。
- 成功必须同时满足：完成所有核心任务、能识别来源/市场时间/采集时间/版本和降级状态、未请求或触发任何交易能力。
- 本研究不评估投资收益、选股能力或任何投资建议质量。

## 研究前提与隐私同意

研究人员在开始前应向参与者说明：系统只展示本地受控的市场事实和历史日线；数据可能处于空、过期、休市或权限受限等降级状态；系统不提供券商连接、下单或自动交易。

参与者必须明确同意后才能开始计时。仅记录研究编号、同意状态、任务过程事件、完成时长、是否请求辅助、结果状态和非敏感观察。不得要求、收集或记录下列信息：

- 券商账户、账户余额、持仓、真实交易或下单信息；
- 投资偏好、风险偏好、收益目标或个人投资决策；
- 密码、密钥、验证码、身份证明、联系方式或其他敏感个人信息。

参与者可在任何时刻拒绝回答、暂停或退出。退出不影响其任何权益；退出记录只标记为“放弃”，不将其计入成功。

## 核心任务

研究人员应在本地应用已启动、且本地演示事实可恢复的条件下提供以下任务说明，不提供操作步骤：

1. 启动本地应用，并恢复或打开本地市场数据。
2. 查看市场状态和主要指数的历史日线。
3. 找到并口头指出数据来源、市场时间、采集时间和数据版本。
4. 识别当前页面是可用、空、过期、休市或权限受限等何种状态，并说明可否进行当前预测。
5. 在遇到降级状态时，确认没有把历史日线当作实时行情，也没有尝试进行交易。

任务不要求输入真实账户、访问真实网络、请求投资建议或进行任何交易。

## 计时、辅助和异常规则

- 计时起点：研究人员完整读出任务说明并确认参与者同意的时刻。
- 计时终点：参与者完成全部核心任务并准确识别所展示的状态、来源、市场时间、采集时间和版本的时刻。
- 成功：在 180 秒内独立完成全部核心任务，且无关键理解错误。
- 失败：超过 180 秒仍未完成、对实时/历史或降级状态作出关键错误判断，或尝试绕过研究边界。
- 放弃：参与者主动停止、拒绝继续或撤回同意；单独记录，不伪装为成功或失败。
- 辅助：研究人员必须逐次记录辅助类型。仅澄清任务文字不算操作辅助；任何指出按钮、菜单、状态答案或操作路径的提示均算辅助，并使该次“独立完成”不成立。
- 异常：应用崩溃、本地数据不可恢复、设备故障、计时器故障或研究人员流程偏离必须记录。异常结果不得纳入成功率，待问题解决后以新编号重测。

## 结果计算与发布规则

完成真实研究后，按下式计算：

```text
独立成功率 = 在 180 秒内独立成功的人数 / 已完成且结果可判定的参与者人数 × 100%
```

只有样本量不少于 10 人且独立成功率不少于 90% 时，才可记录为“可用性验收通过”。放弃和异常必须单列，不得从分母中静默删除；所有剔除均须说明理由。研究记录应仅保留去标识化编号和必要的非敏感观察。
