# US4 板块与成员历史独立验收说明

## 验收范围

本说明对应用户故事 4：查看行业、概念、地域等主要板块，维护自定义板块，并查看板块涨跌、成交活跃度、上涨下跌家数、趋势强度和板块轮动。验收重点是成员有效期、追加式成员历史、覆盖率门禁和禁止误导性排名，不涉及真实交易或投资承诺。

固定风险提示：研究参考，不构成投资建议。

## 独立验收步骤

1. 检查主要板块是否声明分类、市场、币种、来源、数据版本和成员有效期。
2. 检查自定义板块的成员加入和移除是否形成追加式历史，历史记录不得被静默覆盖。
3. 对同一自定义板块分别查询变更前、变更中和变更后的点时成员，确认历史分析只使用当时有效成员。
4. 检查板块指标是否包含涨跌、成交活跃度、上涨下跌家数、趋势强度、轮动分和覆盖率。
5. 当覆盖率不足、成员历史断裂或跨市场币种/交易日历不可比较时，页面必须展示降级说明并禁止误导性排名。
6. 自定义板块页面必须同时展示当前成员和只读成员历史。

## 不允许通过的情况

- 用当前自定义板块成员倒灌历史分析。
- 覆盖率不足时仍显示强弱排名。
- 成员历史断裂时继续生成板块历史结论。
- 未对齐币种、交易日历和市场时间时显示跨市场排名。
- 任何板块页面或报告省略“研究参考，不构成投资建议”。

## 当前结论

US4 的核心验收标准是：板块数据可追溯、成员历史可按时间点复原、覆盖率不足或不可比较时明确降级。后续板块数据源、页面字段或轮动算法变更后，必须重新运行上述门禁。
