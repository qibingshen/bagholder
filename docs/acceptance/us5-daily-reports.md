# US5 每日任务与报告独立验收说明

## 验收范围

本说明对应用户故事 5：每日自动更新数据并生成市场总结、强弱板块、关注个股和预测复盘。US5 只覆盖本地研究任务、模拟报告和恢复流程，不连接券商、不下单、不承诺收益。

固定风险提示：研究参考，不构成投资建议。

## 必跑门禁

## 独立验收步骤

1. 检查 A 股、港股、美股是否分别按各自市场时区生成开盘前、盘中和收盘后任务。
2. 检查休市日不生成每日任务，半日市在提前收盘后生成收盘后报告。
3. 检查美股夏令时和冬令时均保留纽约市场时区，避免 UTC 偏移漂移。
4. 模拟数据源失败或限频，确认任务进入重试、部分成功或失败状态，而不是伪装完成。
5. 检查日报快照是否包含来源、数据版本、缺失范围、降级影响、章节和固定风险提示。
6. 取消或中断任务后，任务中心必须显示恢复点和已完成步骤。
7. 部分成功报告只能发送警告通知，不能发送完整成功通知。

## 不允许通过的情况

- 休市日触发行情更新、回测或报告。
- 延迟、过期或缺失数据被伪装为完整日报。
- 部分成功报告不显示缺失范围和降级影响。
- 任务取消或中断后丢失恢复点。
- 任何报告或通知省略“研究参考，不构成投资建议”。

## 当前结论

US5 的验收重点是：每日任务按市场日历和时区触发，失败不破坏已验证数据，报告保留缺失范围和降级影响，桌面端可查看恢复点并明确区分完整成功与部分成功。
