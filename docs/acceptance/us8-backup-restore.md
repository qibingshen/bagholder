# US8 三平台备份恢复独立验收说明

## 验收范围

本说明对应用户故事 8：在 Windows、macOS、Linux 上保存并恢复本地数据、设置和任务状态。US8 覆盖备份清单、哈希验证、隔离恢复、容量预算、路径适配、导入导出和删除影响确认，不包含券商凭据同步或真实交易能力。

## 必跑门禁

```powershell
py -3.12 -m pytest -o addopts='' tests/contract/test_backup_contract.py tests/property/test_storage_budget.py tests/failure/test_backup_recovery_failures.py -q
```

补充页面检查：

```powershell
py -3.12 -m pytest -o addopts='' tests/contract/test_data_management_page.py -q
```

## 独立验收步骤

1. 在 Windows、macOS、Linux 分别检查平台数据目录是否由集中路径适配生成。
2. 创建备份清单，确认每个文件有 SHA-256 哈希、大小、数据版本和版本链。
3. 模拟损坏包，确认哈希不匹配时拒绝恢复。
4. 模拟中断恢复，确认只能从隔离恢复目录继续，不能直接切换当前数据。
5. 检查凭据、密钥和 `.env` 文件被排除在备份清单之外。
6. 检查容量超过 200 GB 或达到 80% 预警阈值时触发对应门禁。
7. 检查分钟线证券数量和保留天数超过上限时拒绝保存计划。
8. 删除影响确认页面必须阻止不可变工件被静默删除。

## 不允许通过的情况

- 恢复流程直接覆盖当前数据目录。
- 未经只读校验或用户确认就执行原子切换。
- 备份包含凭据、密钥或环境文件。
- 原始行情、预测快照或回测结果等不可变工件被备份清理删除。
- 容量超过 200 GB 或 80% 预警阈值时仍无提示继续写入。

## 当前结论

US8 的验收重点是：备份可校验、恢复可隔离、路径可跨平台、容量有门禁、凭据不进入备份、不可变研究工件不得静默删除。
