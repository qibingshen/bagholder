# US1 市场与历史日线闭环验收记录

## 验收结论

本记录覆盖 US1 的单市场历史日线本地闭环。自动化验收通过的结论只适用于受控的本地实现和注入的固定响应；它不表示已经取得新浪历史日线、复权、公司行动或实时行情的授权，也不表示已经进行过真实网络访问。

## 闭环范围与实现路径

闭环按以下顺序运行：

1. `HistoricalDailyIngestionWorker` 接收注入的固定历史日线响应，并校验来源、证券身份、采集时间、市场时间、字段和价格。
2. 同一批次将原始响应写入 `market-data-raw`，将规范化日线写入 `market-data-normalized`；规范化工件显式保存原始工件父版本。
3. 任一校验或保存失败时，整个批次回滚，原始与规范化工件均不得残留为可见半批次。
4. `MarketService` 只查询本地受控的市场状态、证券目录和历史日线事实，不访问外部数据源。
5. `MarketController` 组合本地市场状态、目录事实与已持久化历史日线，生成本地市场总览模型；市场页面只渲染该模型。

实现定位：

- 注入采集与双工件原子发布：`src/stock_agent/workers/market_ingestion.py`
- 新浪原始响应与规范化报价工件的批次保存：`src/stock_agent/adapters/market_data/sina_provenance.py`
- 本地市场、目录与历史日线查询：`src/stock_agent/application/market_service.py`
- 市场总览组装及降级：`src/stock_agent/desktop/controllers/market_controller.py`
- 市场页面状态及“无实时、无当前预测”门禁：`src/stock_agent/desktop/pages/market_page.py`

## 数据源状态与授权边界

`sina` 仅作为公开只读的 A 股候选来源标识。项目可复核的公开报价 URL 能力为 `http://hq.sinajs.cn/list={代码列表}`，但这不构成对实时行情、历史日线、复权或公司行动数据的授权、承诺或保证。

本闭环的历史日线测试使用注入的固定响应和本地工件，不发起真实网络请求。后续若接入真实历史日线，必须在实施前单独完成合法授权、字段口径、频率限制、保留期限和运行时可用性的复核；未完成复核时，功能必须失败或降级，不能猜测、补齐或拼接其他来源。

## 降级与安全边界

- 历史日线只用于历史研究、展示和回测准备，不能作为当前预测的实时输入。
- 市场时间不可验证、数据延迟不符合规则、休市或日历状态并非 `OPEN` 时，页面必须显示降级状态；不得显示实时数据或开放当前预测。
- 本记录不要求、不保存券商账户、真实交易、投资偏好、密钥或其他敏感个人信息。
- 本项目的研究输出仅供研究参考，不构成投资建议。
