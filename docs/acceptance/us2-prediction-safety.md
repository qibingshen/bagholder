# US2 预测安全独立验收说明

验证日期：2026-07-15

本说明用于验收“获得可解释的概率预测”用户故事。验收对象包括预测领域规则、简单基准生成、预测快照仓储、解释组装、预测详情页和预测控制器。所有预测输出均为研究参考，不构成投资建议。

## 验收范围

- 预测周期仅限 1、5、20 个交易日。
- 输出必须包含上涨、震荡、下跌概率、置信度、主要依据、风险因素、新鲜度、数据版本、特征版本、模型版本和标签规则版本。
- 每个概率和置信度数字必须有结构化数字溯源，且字段值与事实引用逐项一致。
- 当前预测阻断必须在数据过期、延迟、闭市、权限受限或事实不可验证时生效。
- 历史预测快照只能只读展示，不得覆盖原始概率、版本、依据或风险提示。
- 到期结果未验证时必须显示待验证状态，不得提前生成实际方向。
- 所有预测界面、历史快照和解释结果必须显示“研究参考，不构成投资建议”。

## 手工验收步骤

1. 选择一只有有效本地特征、日历、标签规则和行情事实的证券，生成简单基准预测快照。
2. 打开预测详情页，确认页面显示三类概率、置信度、主要依据、风险因素、新鲜度、版本摘要和固定风险提示。
3. 检查每个概率和置信度字段都有数字溯源，且来源包含本地工具、调用时间、数据时点、来源标识和版本。
4. 将当前预测的新鲜度改为过期或延迟，确认当前预测阻断，页面降级为不可用于当前预测。
5. 打开同一证券的历史预测快照，确认历史预测快照仍可只读查看，且显示历史标识和固定风险提示。
6. 对未到期或事实不完整的预测回填结果，确认页面显示待验证，不显示实际上涨、震荡或下跌方向。

## 不允许通过的情况

- 概率、置信度或版本字段缺少数字溯源。
- 使用预测时点之后才可得的未来数据、标签规则、日历或特征。
- 历史预测快照被静默覆盖或被当前结果改写。
- 页面或解释文案包含收益承诺、买卖指令或替代投资建议的表达。
- 延迟、过期或闭市数据被伪装为实时或准实时预测。
- 缺少“研究参考，不构成投资建议”固定提示。
