# 外部研究数据缓存设计

日期：2026-07-27
状态：待用户评审

## 目标

为 TradingAgents 轻量研究所依赖的公开行情与基本面工具数据增加本地缓存，减少对不稳定网站的重复请求，并在上游临时失败时安全回退到仍有效的缓存。

## 范围

缓存的是外部工具的原始、可 JSON 序列化响应，不缓存模型提示词、API Key、模型回答或交易数据。现有日线 `MARKET` 证据机制保持不变。

第一期覆盖轻量研究实际使用的工具：

- `get_stock_data`、`get_indicators`；
- `get_fundamentals`、`get_balance_sheet`、`get_cashflow`、`get_income_statement`；
- `get_profit_forecast`、`get_industry_comparison`。

## 设计

在 TradingAgents 隔离环境中新增一个缓存包装层，所有上述工具先按以下键查找本地缓存：

```text
工具名 + 股票代码 + 标准化参数 JSON + 数据供应商版本
```

缓存实体包含：键、工具名、参数摘要、来源、抓取时间、有效期、原始 JSON 数据和 SHA-256。缓存文件放在 `TRADINGAGENTS_CACHE_DIR/external-data/`；SQLite 索引只在 TradingAgents 自己的缓存目录内维护，不接触主平台交易账本。

有效期：

| 数据 | 有效期 |
|---|---:|
| 历史日线、技术指标 | 24 小时 |
| 三张财务报表、公司基本面 | 24 小时 |
| 估值、机构预期、行业比较 | 1 小时 |

访问顺序：先返回未过期缓存；未命中或过期时请求上游；上游成功后原子写入新缓存；上游失败时仅在存在历史缓存时返回该缓存并标记 `stale=true`。没有缓存时，工具继续抛出原有错误，由分析师在报告中标注数据缺失。

## 安全与正确性

- 不缓存任何模型密钥、请求头、会话令牌或模型输入输出；
- 缓存数据带 SHA-256，读取时复验，篡改或解析失败时删除该条并视为未命中；
- 过期缓存只能用于研究报告，风险结论必须将 `stale` 数据源写入风险标记；
- 不改变主平台的证据、风险、审批或执行安全边界。

## 测试与验收

1. 未过期缓存命中时不调用上游；
2. 缓存过期时刷新并替换；
3. 上游失败但存在历史缓存时返回 `stale=true`；
4. 上游失败且无缓存时保留失败；
5. SHA-256 不匹配时拒绝缓存；
6. 轻量研究对同一股票重复运行时，第二次不再请求已缓存基本面数据。

## 非目标

- 不保证公开网站数据永久可用或实时；
- 不将缓存数据用于实盘报价或订单校验；
- 不引入 Redis、服务器或跨设备共享缓存。
