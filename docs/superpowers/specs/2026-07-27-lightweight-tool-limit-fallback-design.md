# 轻量研究工具轮次降级设计

日期：2026-07-27
状态：已获用户确认

当行情或基本面分析师在限定工具轮次内未生成报告时，系统不再抛出失败。它从已执行的工具消息中提取非空文本，形成带“工具轮次受限”标记的原始报告，并继续调用一次风险结论模型。

轮次上限仍保留为 8，避免无限工具调用。若工具消息没有可用文本，才保留原来的 `LIGHTWEIGHT_ANALYST_TOOL_LIMIT` 失败。降级报告会原样保存在 `market_report` 或 `fundamentals_report`，因此研究证据可追溯，风险模型也能据此给出结论。

测试覆盖：第 8 轮未出报告但有工具输出时返回降级报告；无工具输出时仍失败；已有正常报告的路径不变。
