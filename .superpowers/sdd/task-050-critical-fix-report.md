# T050 预测领域严重安全缺口修复报告

## 已完成修复

- `PredictionInput` 现在拒绝晚于预测时点的市场时点、采集时点和参考价格可得时点；参考价格必须是有限正数。
- 新鲜度改为受限的 `Freshness` 枚举，未知值不能伪装成可用于当前预测的数据。
- `QuantitativeFactReference` 增加并强制校验工具名、工具版本、调用时点、数据时点和 LOCAL/MCP 对应的结果锚定；工具和数据时点不得晚于预测时点。
- 快照追加校验输入输出的证券、数据/特征/模型/标签规则版本及新鲜度一致；保存和返回均采用深拷贝，调用方修改返回对象不会改写仓库内快照。
- 非正或非有限的参考价、到期价安全返回 `PENDING_VALIDATION`，不参与除法。
- 简单基准除 LOCAL 外还校验证券、各版本、调用时点及数据时点均与输入绑定且不晚于预测时点。
- 新增 `OutcomeFactReference`；每项到期价格、交易日历和标签规则均要求保留 LOCAL/MCP 来源、工具和版本、市场/采集/可得时点、结果锚定、事实值及其 SHA-256 值哈希，并验证哈希一致。缺少必要事实时到期结果保持 `PENDING_VALIDATION`；已验证结果将引用持久保存在 `ActualOutcome.fact_references`。公司行动存在时另强制要求 `COMPANY_ACTIONS` 事实引用。
