# T037：一市场历史日线本地闭环集成测试

## 目标

为 US1 首个授权数据源建立可复核选择证据，并以集成测试锁定历史日线采集、原始工件、规范化记录、原子保存及失败回滚。

## 修改范围

- 修改：`docs/acceptance/data-source-selection.md`
- 修改：`tests/integration/test_single_market_daily_pipeline.py`

## 必须先新增并运行失败的测试

1. 选择记录明确首个历史日线闭环仅使用 Sina A 股公开只读能力，列出精确 URL 能力、授权/延迟限制、市场时间/采集时间/版本、未保证实时和预测降级边界；不把 Sina 当成授权实时源。
2. 使用注入的固定历史日线响应，验证采集后原始响应和规范化日线均以追加式本地工件保存，并可按 source、市场时间、采集时间、版本和内容哈希回读关联。
3. 规范化日线应按证券/交易日保存，不得标为实时；相同内容重采集形成可追溯的新采集记录而非静默覆盖；修订需要父版本/来源。
4. 单批任一日线字段不合法、工件保存失败或规范化保存失败时，原始和规范化两侧均不得留下半批记录；报告明确失败原因。
5. 历史日线不能被当前预测当作实时输入。
