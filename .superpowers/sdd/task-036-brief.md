# T036：市场数据失败场景测试

## 目标

为 US1 补充数据源缺字段、过期数据、代码歧义和公司行动异常的失败场景测试，避免任何不完整或不可追溯数据进入研究与当前预测。

## 修改范围

- 修改：`tests/failure/test_market_data_failures.py`

## 必须先新增并运行失败的测试

1. 对原始行情缺少交易日期、市场时间、开高低收、成交量、币种、复权口径、来源、采集时间或数据版本的每一种情况，历史日线标准化/保存必须整批失败，且不产生部分持久化记录。
2. 对 `DELAYED`、`STALE`、`CLOSED` 与市场时间不可验证的行情，当前预测入口必须拒绝，并在错误/状态中明确数据过期或不可用，禁止伪装实时。
3. 对 A/H/美三市场代码歧义（同显示代码、错误交易所、错误币种、未带市场前缀的非唯一代码），证券解析必须要求明确市场/交易所，不能猜测或混用。
4. 公司行动缺失、日期无时区、复权比例不合法、与证券/市场不一致或覆盖已有版本时，必须拒绝；原始行情和预测快照不可被静默覆盖。

## 约束

- 本任务仅写测试与报告，不实现生产代码。
- 新增测试必须在实现前以真实缺失接口/行为失败；测试中不得嵌入替代实现。
- 说明和文档字符串使用简体中文，不增加 HTTP、券商、下单或交易能力。
