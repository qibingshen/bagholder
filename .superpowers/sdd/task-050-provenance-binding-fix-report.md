# T050 预测事实引用绑定修复报告

## 修复范围

- `QuantitativeFactReference` 现在分别保存市场时点、采集时点与可得时点；三者与数据时点、工具调用时点保持顺序，且均不得晚于预测时点。
- `OutcomeFactReference` 现在绑定目标证券、预测快照标识和预测时点，并强制市场时点、采集时点、可得时点的完整顺序。
- 到期结果解析逐项比对引用与实际输入：参考/到期价格值、价格数据版本、交易日历版本及内容摘要、标签规则版本及阈值摘要、公司行动集合及每项行动摘要。
- 任一来源、绑定、版本、值、摘要或时间线不完整/不匹配时，结果保持 `PENDING_VALIDATION`，且不在结果中保留待持久化的事实引用。
- 快照仓库仅接受带完整绑定引用的 `VALIDATED` 到期结果；价格数据版本必须等于预测快照的数据版本。
