# 实施计划：本地量化股票分析智能体

**分支**：`001-local-stock-agent` | **日期**：2026-07-10 | **规格**：[spec.md](spec.md)
**输入**：已确认的产品规格、澄清记录与项目宪法。

## 摘要

构建 Windows、macOS、Linux 上运行的本地量化股票研究桌面应用。PySide6 桌面端经由本地应用服务
访问已验证的行情、板块、预测、报告、任务和模型数据；后台队列与独立训练进程处理耗时计算；
Skill 通过本机只读 MCP 查询和启动非破坏性分析。数据以 DuckDB 元数据、Parquet 不可变时序、
SQLite 桌面状态及模型注册表分层保存。所有结果先暂存、校验、原子提交，确保无未来数据泄漏、
数字可追溯、候选模型受控发布及可回滚。

## 技术上下文

**Language/Version**: Python 3.12（主语言/版本；支持范围在打包验证中锁定）
**Primary Dependencies**: PySide6、DuckDB、PyArrow、Pydantic、MCP SDK、pytest、Hypothesis、
PyInstaller 或等效平台打包工具
**存储**：DuckDB 元数据与审计；Parquet 行情/特征/回测工件；SQLite 桌面状态；模型文件与注册表
**测试**：pytest 单元/契约/集成；时间一致性与未来数据泄漏；故障恢复；三平台安装、启动、备份恢复
**目标平台**：Windows 10/11、macOS（Apple Silicon 与 Intel）、Ubuntu 22.04/24.04
**项目类型**：单用户跨平台本地桌面应用
**性能目标**：规格容量边界内，单证券日线、两年分钟线、板块当日指标和预测快照查询分别建立
冷/热缓存基准；每日数据就绪后 10 分钟内生成完整报告；失败 1 分钟内显示降级状态
**约束**：本地事实来源；200 GB 默认预算和 80% 门禁；无券商/真实交易；MCP 仅本机最小权限；
预测免责声明；中文文档与注释；三平台分别验收
**规模/范围**：最多 15,000 只证券、10 年日线、500 只证券两年分钟线；A 股、港股、美股；
1/5/20 交易日概率预测

## 进程边界与数据流

```text
PySide6 Desktop ─┐
Local MCP Server ├─> Local Application Service ─> DuckDB / Parquet / SQLite / Model Registry
Skill Orchestrator┘              │
                                ├─> Persistent Task Queue ─> Worker Processes
                                └─> Training Process (candidate-only)
```

1. 桌面端和 MCP 发送版本化请求；应用服务校验权限、参数、市场规则和数据新鲜度。
2. 查询只读取已提交版本；写入型工作创建任务并写入暂存区。
3. 工作者完成后由应用服务执行完整性校验、版本登记和原子发布。
4. 训练只登记候选模型；发布与回滚只能由本机桌面端确认。
5. 所有用户可见数字携带工具结果、数据版本、模型版本和审计关联标识。

## 数据版本与恢复策略

- 数据批次记录来源、供应商版本、市场时间范围、采集 UTC 时间、模式版本、哈希、父版本及修订原因。
- Parquet 目录按数据集/市场/时间或证券集合/版本分区，并有 `manifest`、文件哈希和完成标记。
- DuckDB 事务登记版本、清单、任务结果与当前推荐引用；预测、报告、回测固定实际使用的版本清单。
- SQLite 只保存可重建的桌面状态；量化事实、模型状态和审计不以 SQLite 为唯一来源。
- 备份采用清单化一致性快照；恢复先隔离校验后原子切换，凭据不进入备份。

## 任务与模型状态机

**任务状态**：`QUEUED → VALIDATING → RUNNING → STAGING → VERIFYING → SUCCEEDED`；
可分支为 `RETRY_WAIT`、`CANCEL_REQUESTED`、`CANCELLED`、`INTERRUPTED`、`FAILED`。

**模型状态**：`TRAINED → BACKTEST_PASSED → BASELINE_PASSED → SHADOW_RUNNING →
SHADOW_PASSED → AWAITING_LOCAL_APPROVAL → RELEASED`；失败为 `GATE_FAILED` 或 `REJECTED`。

状态迁移、重试、批准、发布和回滚均产生不可变审计事件。未来数据泄漏、权限拒绝、契约错误、
完整性失败和严重故障不得自动重试。

## 跨市场、错误降级与平台交付

- 市场规则服务集中处理代码、时区、交易日历、交易阶段、币种、公司行动和复权；跨币种比较引用汇率版本。
- A 股 5 秒、港股/美股 15 秒内为实时；60 秒内准实时；15 分钟内延迟；交易时段超过 15 分钟过期，
  禁止当前预测；休市显示最近有效时间。
- 数据源短时失败可退避重试；凭据缺失切换许可的公开/本地历史数据；过期、缺字段、泄漏和完整性失败
  不产生当前预测或量化数字。
- 打包分别验证 Windows 10/11、macOS Apple Silicon/Intel、Ubuntu 22.04/24.04；每个平台均验收
  安装、启动、核心流程、升级、备份和恢复。

## 每日调度、导入导出与性能基线

- 调度仅依据版本化市场日历和市场当地时区，不依赖个人电脑时区。默认时点为：A 股开盘前 08:45、
  盘中 09:35/11:25/14:50、收盘后 15:20；港股开盘前 09:15、盘中 10:00/12:00/15:50、收盘后
  16:15；美股按 `America/New_York` 开盘前 08:30、盘中 10:00/15:45、收盘后 16:15。非交易日、
  半日市、临时停市和数据源未就绪时跳过或延后相应任务并记录原因；日报从必需数据有效后 10 分钟内生成。
- 导入仅接收用户有权使用的历史行情或板块数据，先写入暂存区，完成模式、市场、时间、来源、版本、
  重复与完整性校验后才生成新版本。普通导出只允许用户选择报告、派生查询结果或版本化研究快照，
  不含凭据、运行时密钥或未提交数据。全量可迁移交付使用备份包，不以普通导出替代。
- 删除只允许清理可重建缓存、已确认无引用的暂存工件或用户归档的自定义板块；原始行情、预测快照、
  已验证报告和模型审计不能通过普通删除路径移除。所有删除请求展示影响范围、引用状态和恢复可能性，
  并写入审计。
- 参考验收机为 4 核 CPU、16 GB 内存、SSD：冷启动至可交互不超过 5 秒；已索引本地目录、行情或
  板块查询 P95 不超过 2 秒；页面交互 P95 不超过 100 毫秒；任务状态在 1 秒内可见。训练、回测、
  批量导入、备份和报告生成必须后台化。

## 复杂性跟踪

| 复杂性 | 必要原因 | 被否决的简单方案及原因 |
|--------|----------|------------------------|
| 四类本地存储与模型注册表 | 同时满足大体量时序、事务治理、桌面状态和模型可复现 | 单一数据库会混合生命周期或降低分析性能 |
| 多进程后台与训练隔离 | 保护桌面可用性、数据完整性和发布权限 | 在界面进程或单一后台执行会扩大故障域 |
| 版本化市场规则与工件清单 | 三市场时点正确性和预测复现 | 使用显示代码、本机时区或最新文件不可审计 |
