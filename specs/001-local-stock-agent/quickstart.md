# 快速开始与验收指南

## 前置条件

- 使用受支持的 Windows 10/11、macOS Apple Silicon/Intel 或 Ubuntu 22.04/24.04。
- 安装包与用户数据目录分离；首次启动前确认至少保留 20% 可用磁盘空间。
- 如需受授权行情，先在桌面端配置数据源的只读凭据；凭据仅进入操作系统安全凭据库。

## 首次启动

1. 安装对应平台的桌面包并启动。
2. 确认应用创建本地数据、设置、备份、日志、暂存和运行时目录；不在安装目录写业务数据。
3. 在数据源页面查看 A 股、港股、美股授权与新鲜度状态。无有效凭据时，仅启用无需授权公开数据和本地导入历史数据。
4. 选择不超过 500 只证券保存分钟线；确认容量页面显示 200 GB 预算和 80% 预警边界。
5. 打开市场、证券和预测页面，验证来源、市场时间、采集时间、数据版本、状态徽标和“研究参考，不构成投资建议”。

## 核心验收流程

### 行情与预测

1. 为三个市场各选择一只证券。
2. 验证 A 股 5 秒、港股/美股 15 秒内标记实时；60 秒内准实时；15 分钟内延迟；超时为过期。
3. 在过期场景请求当前预测，确认系统拒绝生成且仅保留带原生成时间的历史预测。
4. 查看 1、5、20 交易日三分类概率；确认总和容差、置信度、依据、风险、版本和免责声明齐全。

### 后台任务与恢复

1. 启动行情更新或报告任务；确认桌面仍可浏览已验证历史数据。
2. 模拟数据源失败、取消或工作进程中断；确认任务进入可解释状态，未完成结果不替代完整报告。
3. 检查任务日志不包含凭据，且能按请求、任务、数据版本关联。

### 模型治理

1. 查看候选模型的回测、基准、影子和批准证据。
2. 确认不达 Brier/平衡准确率/30 交易日任一门槛时无法发布。
3. 仅通过本机桌面端批准后发布；执行回滚时确认恢复上一正式版本并保留审计。

### 备份与跨平台

1. 创建备份，检查清单、哈希、数据版本、设置与任务状态；确认不含凭据。
2. 在干净环境或另一受支持平台恢复到隔离目录并校验。
3. 确认后切换；验证行情、板块成员历史、预测、报告、模型注册表、设置和可恢复任务。
4. 测试损坏备份，确认不会覆盖当前有效数据。

## 打包验收

- 每个平台必须在本机或对应原生 CI 构建，使用 `pyside6-deploy` 与固定部署配置；首版采用 standalone
  目录模式，随后封装为平台发行物。
- 每个平台分别验证安装、启动、升级、核心流程、后台崩溃恢复、备份和恢复；未经三平台实测不得
  标记为全平台发布。

## 故障降级

- 数据源限频/超时：显示受影响源、最后有效时间和重试状态。
- 凭据失效：说明授权限制，降级到许可的公开或本地历史数据。
- 休市：显示休市、下次时段和最近有效行情。
- 空间到 80%：停止新增分钟线与非必要扩展采集，提示容量建议，不删除已验证数据。
- MCP 拒绝：返回结构化权限错误；不暴露内部堆栈或凭据。
