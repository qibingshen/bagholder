# 预测契约

`prediction.get` 和 `prediction.list_history` 返回不可变预测快照。每个周期必须包含上涨、震荡、
下跌概率、置信度、主要依据、风险因素、数据新鲜度、数据/特征/模型/标签规则版本、工具结果引用
及原文“研究参考，不构成投资建议”。

- 周期只能为所属市场的 1、5、20 个有效交易日。
- 概率非负且和为 100% ±0.1 个百分点，否则拒绝展示。
- 标签用总回报复权收益率：1 日 ±1%，5 日 ±3%，20 日 ±6%；正阈值及以上上涨，负阈值及以下下跌，其余震荡。
- `STALE`、来源缺失或时间截点不完整时禁止创建当前预测；可返回历史快照并清楚标注生成时间。
- 到期结果作为独立记录关联预测；无有效到期价格时为 `PENDING_VALIDATION`，不得改写预测。
