# 回测契约

`backtest.start_readonly` 仅创建非破坏性分析任务，输入必须定义市场/证券范围、训练/验证/测试窗口、
滚动或扩展方式、标签规则、特征截点、数据版本和成本假设。`backtest.get` 返回运行状态、版本清单、
样本数、Brier score、平衡准确率、分市场/周期指标及可选模拟交易结果。

- 切分严格按市场有效交易日顺序；禁止随机打乱；标签观察期需隔离。
- 任何特征、成员、复权、日历和汇率只能使用预测时点可得版本。
- 模拟交易必须处理手续费、税费、滑点、最小单位、停牌、涨跌停、流动性和不可成交；不得按理想价格填充。
- 发现未来数据泄漏、缺失版本或时间截点错误，任务直接 `FAILED`，结果不得用于模型发布。
